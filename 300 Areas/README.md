# 300 Areas

> Ongoing responsibilities with no end date

---

Areas are the things you are permanently responsible for — they never get "done", they just need to stay in good shape. Health, finances, a domain you own at work, a craft you're keeping sharp.

The test that separates an Area from a Project: **a Project can be completed, an Area can only be maintained.** "Ship the billing rewrite" is a Project. "Keep the billing system healthy" is an Area.

Give each Area its own folder with a hub note. Review them monthly rather than daily — Areas degrade slowly, so checking them often mostly produces noise.
