# Inbox

> **This is the capture zone. Dump everything here without judgment.**

---

## Rules

1. **Don't organize here** — just capture
2. **Process weekly** (weekly review — 30 min)
3. **Target**: Empty by the end of the weekly review

---

## How to Capture Quickly

- **Brain dump**: Create a new note with today's date, use the Brain Dump template
- **Quick idea**: Create a note with a single line, process later
- **Task that doesn't belong to a project yet**: Just write it here

---

## How to Process (at your weekly review)

For each note here, ask:
1. Is this still relevant? → If no, delete.
2. Is this a completed thing? → Move to `900 Archive/`
3. Does this belong to a project? → Move to `200 Projects/[project]/`
4. Is this reference material? → Move to `400 Resources/` or `500 Knowledge/`
5. Is this a meeting note? → Move to `700 Meetings/`
