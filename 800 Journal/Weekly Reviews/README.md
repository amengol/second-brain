# Weekly Reviews

> One note per week, named `YYYY-Www.md` (e.g. `2026-W35.md`).

---

Written by `/wrap-week`. The weekly review is where the daily notes stop being a pile and become a pattern — what actually moved this week, what you avoided, which `next_action` fields went stale, and what the inbox is still holding.

Thirty minutes, once a week. If you only keep one review cadence, keep this one.
