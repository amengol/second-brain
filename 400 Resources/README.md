# 400 Resources

> Reference material you did not write

---

Things you collected because they might be useful later: documentation, saved articles, tool comparisons, checklists, snippets, contract templates.

The distinction from `500 Knowledge/` is authorship. **Resources are material you gathered. Knowledge is understanding you built.** A framework's official docs go here; your notes on how that framework actually behaves in production go in Knowledge.

If a resource has sat here unread for a year, delete it. A reference folder you don't trust is worse than an empty one.
