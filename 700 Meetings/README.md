# 700 Meetings

> Meeting notes, one folder per date

---

One subfolder per date (`YYYY-MM-DD/`), one note per meeting inside it.

These are the highest-fidelity record you have of what was actually said — decisions, commitments, numbers, who owns what. When a project note and a meeting note disagree, **the meeting note is usually right and the project note is stale.**

Write down what was decided and who owes what by when. Everything else is optional.
