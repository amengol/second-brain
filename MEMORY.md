# MEMORY — Durable decisions & lessons

The curated, still-true digest. Loaded into every session, so it stays **short**. The full record lives in the daily notes (`800 Journal/`); only durable items get promoted here. Append with a date; remove items when they stop being true.

**What belongs here:** a decision you'd otherwise re-litigate in three months, a constraint you keep rediscovering the hard way, a lesson that changed how you work. Write the *why*, not just the *what* — a decision without its reasoning is impossible to revisit honestly.

**What does not:** anything the vault already records elsewhere. Project status lives in the Dashboard. What happened lives in the journal. Reference material lives in `400 Resources/`. If it's written down somewhere else, a copy here is just a second thing to keep in sync.

Keep this file short enough to reread in two minutes. When it stops being that, prune it — an unread memory file is the same as no memory file.
